#Pet Examine

Pet Examine adds a useful Examine option to player pets in RuneLite.

Right-click a player’s pet and select Examine to see the stats associated with that pet, such as boss kill count, activity count, or skill XP.

Examine other players’ pets

Shows boss KC, activity totals, or skill XP

Uses local XP for your own skilling pets

Pulls data from the RuneLite hiscores for other players

Supports pets with multiple sources (e.g. Nightmare, Chaos Elemental)

Optional display of the pet owner’s name in the menu

#Notes

Pets must be close enough to determine ownership

Unranked players may show unavailable data

Only applies to player pets
